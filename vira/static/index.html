How to use PDF Library

01

Import a PDF

Open PDF Library, expand Manage PDFs and then Add PDFs. Choose files with selectable text, confirm your rights, and import them. Scanned PDFs need OCR first.

02

Explore the library

Choose Ask a question for a cited answer or Find passages for matching text. Open a result to check its original PDF page.

03

Review the sources

With local Ollama, VIRA drafts an answer from retrieved PDF passages only when its source quotes pass basic checks. Verify each claim on the cited page.

Finding articles with PubMed

Expand Find articles on PubMed under Optional tools. It finds citation details and links, but does not download or import full-text PDFs. To search an article in VIRA, obtain a PDF you are allowed to keep and import it yourself.

Optional hybrid search

Keyword search works without an embedding model. For semantic search, install a local Ollama embedding model, build the index in PDF Library, then choose Hybrid. This is separate from the Ollama model used to draft source-backed answers.
